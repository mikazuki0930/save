My Savings - 貯金記録アプリ

GitHub Pages で使う方法:
1. このZIPを解凍します。
2. index.html, manifest.webmanifest, sw.js, icon.svg をGitHubリポジトリのルートにアップロードします。
3. Settings > Pages > Deploy from a branch > main / (root) を選びます。
4. 公開されたURLをiPhoneのSafariで開き、共有 > ホーム画面に追加。

使い方: 月末残金を月ごとに記録。前月の記録がある場合、差額を月間貯金として表示します。間の月の記録が欠けている場合、その月の月間貯金は算出しません。

データはブラウザのlocalStorageに保存。同期はありません。定期的にバックアップJSONを書き出してください。
